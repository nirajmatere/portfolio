# Technical Documentation: `src/i18n/i18n.js`

## Overview

The `src/i18n/i18n.js` file is responsible for setting up and configuring internationalization (i18n) for the application using the `i18next` library, integrated with React via `react-i18next` and browser language detection via `i18next-browser-languagedetector`. 

It imports English and Japanese JSON translation files, configures language detection rules and fallbacks, disables manual interpolation escaping, and exports the initialized `i18n` instance for use across the application.

---

## File Details

* **File Path:** `src/i18n/i18n.js`
* **Module Type:** ES Module (JavaScript)

---

## Dependencies & Imports

```javascript
import i18n from 'i18next';
import { initReactI18next } from 'react-i18next';
import LanguageDetector from 'i18next-browser-languagedetector';

import en from './en.json';
import jp from './jp.json';
```

| Import | Source | Description |
| :--- | :--- | :--- |
| `i18n` | `'i18next'` | The core internationalization library instance. |
| `initReactI18next` | `'react-i18next'` | Plugin module that connects `i18next` to React. |
| `LanguageDetector` | `'i18next-browser-languagedetector'` | Plugin to detect the user's language in the browser environment. |
| `en` | `'./en.json'` | Local JSON resource file containing English translation strings. |
| `jp` | `'./jp.json'` | Local JSON resource file containing Japanese translation strings. |

---

## Configuration & Initialization

The module executes a chained configuration sequence using `.use()` for plugins and `.init()` for options.

```javascript
i18n
  .use(LanguageDetector)
  .use(initReactI18next)
  .init({
    resources: {
      en: { translation: en },
      jp: { translation: jp }
    },
    fallbackLng: 'en',
    interpolation: {
      escapeValue: false
    },
    detection: {
      order: ['localStorage', 'navigator'],
      caches: ['localStorage']
    }
  });
```

### Chained Plugins (`.use`)

1. **`i18n.use(LanguageDetector)`**: Registers the browser language detector plugin.
2. **`i18n.use(initReactI18next)`**: Passes the `i18n` instance down to `react-i18next` so React components can bind to it.

### Initialization Options (`.init`)

* **`resources`**: Defines the translation resources available to the application.
  * **`en`**: Maps the imported `en.json` content under the default namespace `translation`.
  * **`jp`**: Maps the imported `jp.json` content under the default namespace `translation`.
* **`fallbackLng`**: Set to `'en'`. If a requested language key or detected language is missing, the application falls back to English.
* **`interpolation.escapeValue`**: Set to `false`. Disables character escaping for interpolation because React natively handles Cross-Site Scripting (XSS) prevention.
* **`detection`**: Configures how the user's language preference is detected and stored:
  * **`order`**: Specifies the lookup sequence `['localStorage', 'navigator']`.
    1. Checks `localStorage` first for a saved language preference.
    2. Falls back to checking the browser's language setting via `navigator` if no entry exists in `localStorage`.
  * **`caches`**: Set to `['localStorage']`. Persists the detected or selected language in the browser's `localStorage`.

## Export

```javascript
export default i18n;
```

* **Type:** Default export
* **Exported Value:** The fully configured `i18n` instance.

---

## Execution Flow

1. Imports core modules (`i18next`), React integration bindings (`react-i18next`), detection middleware (`i18next-browser-languagedetector`), and language resource files (`en.json`, `jp.json`).
2. Attaches the language detector and React integration plugins to the `i18n` instance.
3. Initializes the instance with translation resources (`en`, `jp`), a fallback language (`'en'`), disabled interpolation escaping, and `localStorage`/`navigator` language detection rules.
4. Exports the instance as the default export.
