# Technical Documentation: `eslint.config.js`

## Overview

The `eslint.config.js` file serves as the flat configuration file for ESLint in the project. It defines the linting rules, language options, parser configurations, and file target patterns used to enforce code quality and stylistic consistency across JavaScript and React (`.js` and `.jsx`) files.

---

## Imported Modules

The configuration imports the following packages and helper utilities:

| Import | Source | Description |
| :--- | :--- | :--- |
| `js` | `@eslint/js` | Provides official standard JavaScript configurations recommended by ESLint. |
| `globals` | `globals` | Supplies predefined sets of global variables (e.g., browser environment globals). |
| `reactHooks` | `eslint-plugin-react-hooks` | ESLint plugin enforcing Rules of Hooks for React. |
| `reactRefresh` | `eslint-plugin-react-refresh` | ESLint plugin validating React Refresh integration for Vite. |
| `defineConfig`, `globalIgnores` | `eslint/config` | Utility functions from ESLint to define and validate configuration objects and declare globally ignored paths. |

---

## Configuration Breakdown

The file default-exports the result of calling `defineConfig()`, passing an array of configuration objects.

```javascript
export default defineConfig([ ... ])
```

### 1. Global Ignores

```javascript
globalIgnores(['dist'])
```
* **Function**: `globalIgnores(['dist'])`
* **Purpose**: Configures ESLint to globally exclude the `dist` directory from linting.

---

### 2. File Matching and Language Options

```javascript
{
  files: ['**/*.{js,jsx}'],
  // ...
  languageOptions: {
    globals: globals.browser,
    parserOptions: { ecmaFeatures: { jsx: true } },
  },
}
```

* **Target Files (`files`)**: Applies the specified rules and configurations to all files matching the glob pattern `**/*.{js,jsx}` (all `.js` and `.jsx` files in any directory).
* **Language Options (`languageOptions`)**:
  * **`globals`**: Sets `globals.browser`, enabling standard browser global variables (such as `window`, `document`, etc.) so ESLint does not flag them as undefined.
  * **`parserOptions.ecmaFeatures.jsx`**: Set to `true` to enable parsing support for JSX syntax.

---

### 3. Extended Rulesets (`extends`)

The object extends three configuration presets:

```javascript
extends: [
  js.configs.recommended,
  reactHooks.configs.flat.recommended,
  reactRefresh.configs.vite,
]
```

1. **`js.configs.recommended`**: Applies standard recommended rules from `@eslint/js` for identifying core JavaScript errors and code smells.
2. **`reactHooks.configs.flat.recommended`**: Applies recommended rules for React Hooks from `eslint-plugin-react-hooks`.
3. **`reactRefresh.configs.vite`**: Applies Vite-specific rules for React Refresh from `eslint-plugin-react-refresh`.

---

## How It Works

1. **Export Call**: ESLint loads `eslint.config.js` as an ES module and evaluates the default export generated by `defineConfig`.
2. **Ignore Evaluation**: Files located inside the `dist` folder are globally skipped via `globalIgnores(['dist'])`.
3. **Matching & Rule Application**:
   * For files matching `**/*.{js,jsx}`, ESLint configures browser globals and enables JSX parsing.
   * It merges and enforces the rules defined in `js.configs.recommended`, `reactHooks.configs.flat.recommended`, and `reactRefresh.configs.vite`.
